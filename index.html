Projetos Acadêmicos

Projetos desenvolvidos em equipe durante o curso, no formato ABP (Aprendizagem Baseada em Projetos).

1º Semestre

Projeto ABP – 1º DSM

Aplicação web para consulta de horários, professores e salas da Fatec Jacareí.

Descrição

Sistema desenvolvido em equipe para centralizar a consulta da grade de horários da instituição, substituindo planilhas e avisos dispersos por uma interface web única, com dados de disciplinas, docentes e salas.

Minha contribuição

  • Prototipação das telas no Figma, definindo layout e fluxo de navegação.
  • Desenvolvimento do front-end em HTML e CSS a partir do protótipo.
  • Implementação de funcionalidades em JavaScript (filtros e exibição dos horários).
  • Participação na modelagem do sistema com Astah.

Tecnologias

HTML CSS JavaScript Figma Astah PostgreSQL pgAdmin

2º Semestre

Projeto ABP – 2º DSM

Plataforma web para visualizar, comparar e extrair dados limnológicos.

Descrição

Projeto construído sobre uma base de dados fornecida pelo INPE, permitindo a visualização e comparação de dados limnológicos de corpos d'água, além da exportação das informações para análise posterior.

Minha contribuição

  • Desenvolvimento de componentes da interface em React com TypeScript.
  • Integração do front-end com os dados vindos do back-end.
  • Criação do protótipo de telas no Figma junto com a equipe.
  • Apoio na modelagem do sistema (Astah / StarUML).

Tecnologias

TypeScript React Node.js Figma Astah StarUML

3º Semestre

Projeto ABP – 3º DSM

Aplicação com foco em integração de dados via API e consultas em banco relacional.

Descrição

Projeto desenvolvido em equipe com ênfase em back-end: construção da lógica de API responsável por tratar, validar e entregar os dados consumidos pela aplicação, apoiada em consultas SQL sobre um banco de dados relacional.

Minha contribuição

  • Desenvolvimento da lógica de API em TypeScript (rotas, tratamento de requisições e respostas).
  • Escrita e otimização de consultas SQL para alimentar os endpoints.
  • Validação de dados e tratamento de erros na comunicação entre front-end e back-end.
  • Testes das integrações para garantir a consistência dos retornos.

Tecnologias

TypeScript SQL API REST Node.js Git
